PUBLISH ON GITHUB PAGES FOR FREE
1. Open your public website repository on GitHub.
2. If your GitHub Pages setting uses main /docs, upload index.html into the docs folder.
   If it uses main /(root), upload index.html at the repository's top level.
3. The filename must be exactly index.html (lowercase).
4. Open Settings > Pages and confirm the selected branch and folder match where index.html is stored.
5. Wait for the Pages deployment to finish, then open the published URL.
